# Portfolio — Putri Zukhruf Dinata

Website portofolio statis, responsif, dan siap deploy ke Vercel.

## Deploy cepat ke Vercel
1. Ekstrak ZIP ini.
2. Buat repository baru di GitHub dan unggah `index.html`, `vercel.json`, dan `README.md`.
3. Masuk ke https://vercel.com/new lalu pilih repository tersebut.
4. Framework Preset: **Other**. Build Command dan Output Directory dapat dikosongkan.
5. Klik **Deploy**.
